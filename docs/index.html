OpenBot

本地优先的 AI agent 运行时 —— Grok Bot / Muse 类产品的开源本地复刻
MIT License Node ≥ 20.12 本地端口 4132
这不是在线应用。OpenBot 是 local-first 的 Node 服务：它在本机监听 4132 端口，数据写入 ~/.openbot。 GitHub Pages 只能托管这个静态说明页，无法在这里运行服务。 要真正使用，请在本地按下面的步骤启动。

它是什么

  • 在本机跑一个 agent 服务（默认 http://localhost:4132）
  • 暴露小型事件 API，并通过 Server-Sent Events 向客户端流式推送
  • channels / threads / agents / plugins / config 存放在 ~/.openbot
  • 自带 system agent（LLM 运行时 + 存储工具）与 state agent（确定性存储读取，不走 LLM）
  • 可从 ~/.openbot/agents/<agent-id>/AGENT.md 载入自定义 agent

本地运行

git clone https://github.com/sjkncs/openbot.git
cd openbot
pnpm install
pnpm build
pnpm start        # → http://localhost:4132
需要 Node >= 20.12.0。pnpm dev 可热重载开发。
